# ESP32_Communication

If Ping is received on **ESP32**, Telemetry is Transmitted. Temperature and Sensor readings are then received back. If a pulse is received on **D13** pin, **ESP32** resets.

## Features

Organized source codes in a single directory Organized includes in a single directory.
Use of **PlatformIO**

## Prerequisites

**PlatformIO** ≥ 3.3.4

## Further Requirements

1. Use **Build** command of **PlatformIO** to build the code
2. Use **Upload** command of **PlatformIO** to feed the code to **ESP32**
3. Use **Monitor** command of **PlatformIO** to monitor output
